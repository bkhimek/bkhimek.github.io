Cross-Caller Concordance — GATK vs DeepVariant, before and after digging in

GATK HaplotypeCaller and DeepVariant were run independently against the same aligned, deduplicated CAPN3/DMD reads and cross-checked with bcftools isec. The raw numbers look like a real disagreement — 2,318 vs 3,170 calls, only 2,271 shared. Following the flow below shows what that apparent 899-call gap actually is.

90% of the apparent disagreement wasn't disagreement. DeepVariant reports a record for every candidate site it examines, not only confident calls — so most of its 899 "private" records are RefCall/NoCall bookkeeping, not genuine variant calls the two tools actually disagree on. Only 94 of the 899 are real PASS-filtered calls unique to DeepVariant. Both callers' totals reconcile exactly: 2,318 = 47 + 2,271, and 3,170 = 899 + 2,271.
Source: CROSS_CHECK_VCFS module output, CAPN3/DMD Variant Calling Pipeline README (github.com/bkhimek/CAPN3-DMD-variant-calling-pipeline), Status: Complete, all 9 modules verified end-to-end.
