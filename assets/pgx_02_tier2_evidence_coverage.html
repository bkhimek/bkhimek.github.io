Tier 2 Evidence Coverage — Gene → Drug Recommendation Map

Every recommendation traces to a specific, versioned CPIC/ClinPGx guideline — this diagram shows which of the five genes feed which of the seven drug recommendations this pipeline currently implements, including its two structurally distinct extension patterns: one gene driving more than one drug recommendation, and a recommendation computed jointly from two genes' phenotypes at once. Click a node to trace its flows; hover a link for the underlying guideline table.

Two extension patterns proven here, not just five separate lookups. CYP2C19 is this project's first gene with more than one drug pairing — the same phenotype implies opposite clinical urgency for clopidogrel (activation) versus voriconazole (clearance). TPMT and NUDT15 are this project's first compound recommendation: when both genes' phenotypes are available together, evidence.recommend_compound_thiopurine() uses CPIC's joint dosing tables instead of either gene's solo table — selectable per drug via cli.py --thiopurine-drug.

See pgx_interpreter/evidence.py and docs/GENE_SCOPE.md in the project repository for the full guideline citations and versioning behind every link below.
